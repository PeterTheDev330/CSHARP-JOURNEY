# C# Lessons

My journey from complete beginner to a deployed ASP.NET Core Web API, following a 12-week plan (Oct 9 - Dec 31, 2026).

## About

This repository holds everything I write while learning C#. Each week has its own folder, and each lesson or build inside it is its own project, so any of them can be run on its own.

## Structure

```
SERIOUS C# LESSONS/
├── .gitignore

```

## How to run a project

1. Install the [.NET SDK](https://dotnet.microsoft.com/download).
2. Open a terminal in the project folder, for example:

```
cd WEEK_ONE/LessonOne
dotnet run
```
